# PR のコミットを積み直して force push する

この skill を呼んだこと自体を、履歴の書き換えと force push の指示として扱う（commit-workflow の「例外」）。分割案の事前の合意も省く。それ以外は commit-workflow に従う。

PR（省略時は現在のブランチの PR）のコミットと作業ツリーの未コミットの変更を、レビューしやすい単位に積み直す。途中で足して後で打ち消した変更は履歴に残さない。未コミットの変更は、それが直している元のコミットに統合する。積み直した結果は報告で示す。

- 作成者が自分でない、他者のレビューが付いている、手元の HEAD と PR の head が違う、のいずれかなら書き換えずに止めて理由を伝える。
- 書き換えの前に、未コミットの変更も含めた今の状態をバックアップのブランチに残す。
- 積み直した後の内容が、バックアップと完全に一致することを diff で確かめる。一致しなければ push しない。
- push は元の head を指定した `--force-with-lease` で行う。
- このブランチを base にした PR があれば、rebase はせず報告に書く。

報告には、積み直す前と後のコミットの一覧、内容が一致したこと、検証の結果、バックアップのブランチ名を書く。
