# settings-review

dotfiles のリポジトリ（`$DOTFILES_DIR`）直下の `.settings-review-handoff.md` を読み、その「次回の進め方」に沿って作業を始める。

ファイルが無ければ、そう伝えて止める。引数があれば、引き継ぎメモより優先する追加の指示として扱う。

## 実行環境に合わせる

- 見直す対象は Claude の設定とログ。Codex から実行しても、Codex の設定や履歴へ読み替えない。
- `$DOTFILES_DIR` が未設定なら、この SKILL.md のリンク先から dotfiles リポジトリのルートを特定する。推測したパスのファイルを作らない。
- 引き継ぎメモの専用 skill・Claude Docs・Artifact は、実行環境で利用できるかを先に確認する。Codex では接続済みドキュメントの一覧と対応操作から、同じ文書を読み書きできるか確認する。必要な操作や必須の skill がなければ、その工程を未実施として報告する。別の文書やサービスへ保存先を変えない。
- ファイル読取・検索・シェル実行は、利用可能な同等のツールで行う。設定の反映範囲と確認条件は引き継ぎメモに従い、権限・MCP 接続・認証設定を変えて不足を補わない。
