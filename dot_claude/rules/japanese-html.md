# 和文を含む HTML のレイアウト

和文は 1 字ごとに改行できるので、箱が狭すぎてもはみ出さずに縦長に崩れ、見落としやすい。HTML を作るときは次を守る。

- 本文の行長は 1 行 35〜45 字を目安にする。和文 1 字はほぼ 1em なので、上限は `em` で決める。`ch` は英字の幅で和文 1 字の約半分しかなく、英文向けの「65ch」をそのまま使うと狭すぎる。上限は段落・箇条書き・見出しに掛け、表やカード群には掛けない。
- grid の自動配置で、本文が番号やアイコン用の狭い列に落ちないようにする。子（`::before` を含む）の数が列数と合わないときは、各子の置き場所を明示する。
- 表は列を潰して縦に伸ばさず、横スクロールに逃がす。折り返すと読めなくなる列（見出し・ラベル・ID・数値）は折り返さない指定にし、表にはその列が収まる最小幅を与える。
