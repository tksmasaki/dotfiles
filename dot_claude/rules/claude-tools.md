# Claude Code の道具の使い方

## 動作確認のブラウザ

画面を見て行う動作確認は Claude in Chrome で行う。アプリ内のブラウザは使わない。Chrome に接続できないときは、切り替えずに止めて伝える。画面幅を変えた計測や自動実行には Playwright を使ってよい。

## 冗長な出力が出る作業はサブエージェントに委譲する

自己完結していて要約だけ返せば済む作業を渡す。往復や段階をまたぐ文脈の共有が要るものはメインで行う。

要約と確かめられなかった点だけを返させる。ログ本文はパスで受け取る。

調査を依頼するときは、対象ディレクトリの絶対パスを prompt に書く。

Explore と Plan は CLAUDE.md を読まない。この 2 つに効かせたいルールは委譲時のプロンプトで言い直す。

fork はメインのモデルとコンテキストを継承する。モデルを下げる目的の委譲では fork を使わない。
