# 見てほしい箇所の指示を受ける

この skill の役割は、ユーザーが挙げた点を受け取り、レビュワーに渡せる形に確定して保持すること。diff コメントにするか body に置くか、どう書くかは `~/.claude/skills/pr-description/SKILL.md` に従う。

扱うのはユーザーが挙げた点だけ。自分が重要だと判断した箇所を足さない。保持する点が無ければ、pr-description は「見てほしい箇所」の節を作らない。

挙げたい箇所が思い浮かんだときは、この skill に足さず summary で伝える。採るかはユーザーが決める。

## 箇所と観点に分ける

指示 1 件ごとに、次の 2 つを確定する。

- 箇所: ファイルパスと行（範囲）。関数名・機能名で言われたときは該当行を自分で特定する。候補が複数あるとき、または特定できないときは候補を示してユーザーに決めてもらう。推測で 1 つに決めない
- 観点: レビュワーに何を判断してほしいか。「確認してほしい」だけでは観点にならない。この命名で意図が通じるか、この範囲まで変更を広げた判断が妥当か、この定数の値が妥当か、のように判断の対象まで確定する

ユーザーの意図を書き換えない。レビュワーに通じるよう言い回しを整えるのは構わないが、観点そのものを自分の解釈に差し替えない。

## 確定したら復唱して保持する

箇所（`ファイル:行`）と観点の対にして読み上げ、ユーザーに違いが無いか確かめる。確定した対を以降の PR 操作で参照する。

指示が増えたら足し、ユーザーが取り下げたら落とす。1 つの箇所に複数の観点が付くこともある。

## 反映は pr-description に渡す

保持した点は、PR を作る・body を更新するタイミングで pr-description skill の手順に従って反映する。PR がまだ無いなら保持だけしておく。
